# Camera Inspector

基于 Qt5 + OpenCV + MindVision SDK（MVSDK）的工业相机采集与检测工具。

## 项目结构

```
camera/
├── main.cpp              # 主程序入口（inspector）
├── main_green.cpp        # 绿色通道检测程序入口（green_inspector）
├── mainwindow.h/cpp      # 主窗口：相机控制 + 图像显示
├── green_window.h/cpp    # 绿色通道检测窗口
├── include/              # MVSDK 头文件
├── Makefile
└── README.md
```

## 编译

### 依赖

| 依赖 | 说明 |
|------|------|
| Qt5 (Widgets / GUI / Core) | UI 框架 |
| OpenCV 4 | 图像处理 |
| MVSDK (`libMVSDK`) | MindVision 相机 SDK |
| g++ (C++17) | 编译器 |

### 构建

```bash
make          # 编译 inspector 和 green_inspector
make clean    # 清理产物
```

## 运行

```bash
./inspector          # 主检测窗口
./green_inspector    # 绿色通道检测窗口
```

## 功能说明

### 相机控制

- **连接 / 断开**：自动枚举第一个 MindVision 设备并初始化
- **分辨率**：初始化时优先选择 **4096 × 2048**，若不存在则回退到预设列表第 4 项；支持运行时切换
- **曝光时间**：初始值 36 µs，可通过滑块（行数）或数值框（µs）调节
- **模拟增益**：初始化为最大增益，可通过滑块调节
- **帧/行频**：可通过输入对话框设置，单位 Hz

### 图像采集

- 后台线程持续采集，通过 `QTimer` 定时刷新 UI（约 30 fps 显示）
- 支持单色（MONO8）和彩色（BGR8）两种输出格式
- 采集图像自动保存为带时间戳的文件，计数从 1 递增

### UI 布局

```
┌─────────────────────────────────────────────┐
│                   Header                     │
├──────────┬──────────────────┬───────────────┤
│          │                  │               │
│ Sidebar  │   Image View     │   Analytics   │
│ (控制面板)│  (相机实时画面)  │  (数据面板)   │
│          │                  │               │
├──────────┴──────────────────┴───────────────┤
│              Results Table                   │
├─────────────────────────────────────────────┤
│                  Status Bar                  │
└─────────────────────────────────────────────┘
```

- **F11 / Esc**：切换图像全屏模式（全屏时隐藏所有面板，仅显示图像）

## 默认参数

| 参数 | 默认值 |
|------|--------|
| 分辨率 | 4096 × 2048 |
| 曝光时间 | 36 µs |
| 模拟增益 | 最大值（由相机能力决定） |
| 输出格式 | BGR8（彩色）/ MONO8（单色，取决于相机） |
